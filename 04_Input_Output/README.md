# Chapter 04: Input and Output

## Overview
This chapter covers input and output operations in C programming.

## Topics Covered
- printf() and scanf()
- Format Specifiers
- Multiple Input
- scanf() Return Value
- getchar() and putchar()
- Whitespace Handling
- Field Width and Precision
- Escape Sequences

## Practice Problems

### 01. Precision Challenge
**Problem:** Take three product prices and a discount amount. Calculate the total price, discounted price, average price, and integer average.

**Sample Input**
```text
125.50 249.75 399.90
25.50
```

**Sample Output**
```text
Total Price          : 775.15
After Discount       : 749.65
Average Price        : 249.88
Integer Average      : 249
```

### 02. Input Success Counter
**Problem:** Read two integers and one double. Display how many inputs were successfully read by scanf().

**Sample Input**
```text
10 20 35.5
```

**Sample Output**
```text
Successful Inputs: 3
```

### 03. Character Code Analyzer
**Problem:** Read two characters using getchar(). Display their character codes and the sum of those codes.

### 04. Character Echo
**Problem:** Read one character using getchar() and display it three times using putchar().

### 05. Escape Sequence Practice
**Problem:** Practice escape sequences such as \n, \t, \\, and \".
